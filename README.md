# 유튜브 & 인스타 다운로더

유튜브·인스타그램 링크를 입력하면 영상 정보를 분석하고, 영상(MP4)·썸네일·스크립트(자막)·화면 속 글자를 추출/저장할 수 있는 **로컬 전용** 웹앱입니다.

> 로컬 전용 · 내 PC에서만 동작합니다. 개인적 용도로만 사용하세요. 저작권 및 각 플랫폼 이용약관을 준수할 책임은 사용자에게 있습니다.

## 주요 기능

- 🔍 **분석**: 링크를 붙여넣으면 제목/채널/조회수/좋아요/댓글/업로드일/재생시간/썸네일을 가져옵니다.
- ⬇ **영상 다운로드 (MP4)**: 최고 화질 mp4로 저장합니다.
- 🖼 **썸네일 저장**: 원본 화질 썸네일 이미지를 저장합니다.
- 📄 **스크립트 추출**: 자막(자동 생성 포함)을 텍스트로 추출합니다.
- 🔤 **화면 글자 추출**: 영상 프레임을 일정 간격으로 캡처해 OCR로 화면에 노출된 글자를 추출합니다. (인스타그램 카드뉴스는 이미지에서 바로 추출)
- 인스타그램 **카드뉴스(이미지 캐러셀)**: `gallery-dl`이 설치되어 있으면 이미지 전체를 ZIP으로 저장할 수 있습니다.

## 설치

1. **Node.js 18 이상**과 **Python 3 + pip**가 필요합니다.
2. 핵심 엔진인 `yt-dlp`를 설치합니다. (영상 정보 조회 · 다운로드 · 자막 추출에 사용)

   ```bash
   pip install -U yt-dlp
   ```

   설치 후 터미널에서 `yt-dlp --version`이 정상 출력되는지 확인하세요. (앱이 시스템 PATH에서 자동으로 찾습니다)

3. 프로젝트 폴더에서 Node 의존성을 설치합니다.

   ```bash
   npm install
   ```

   `ffmpeg-static`이 화면 글자 추출(OCR)에 필요한 `ffmpeg` 실행 파일을 자동으로 내려받습니다. 별도 설치가 필요 없습니다.

4. (선택) 인스타그램 **카드뉴스/이미지 게시물** 저장 및 OCR을 지원하려면 `gallery-dl`을 추가로 설치하세요.

   ```bash
   pip install -U gallery-dl
   ```

   설치하지 않아도 유튜브 영상, 인스타그램 릴스/동영상 게시물 기능은 정상 동작합니다.

## 실행

### Windows: 더블클릭 한 번으로 실행

최초 설치(1~4단계)를 마쳤다면, 그 다음부터는 폴더 안의 **`다운로더_시작.bat`**를 더블클릭하면 됩니다.

- 처음 실행 시 필요한 경우 `npm install`을 자동으로 먼저 실행합니다.
- 서버를 켠 뒤 3초 후 브라우저가 자동으로 열립니다.
- 사용을 마치면 열린 검은 창을 닫으면 서버가 종료됩니다.

바탕화면에 바로가기를 두고 싶다면 `다운로더_시작.bat` 파일을 마우스 우클릭 → **바로 가기 만들기** → 만들어진 바로가기를 바탕화면으로 이동하면 됩니다.

### 터미널에서 직접 실행 (Mac 포함)

```bash
npm start
```

브라우저에서 `http://localhost:3000` 접속 후 링크를 입력하고 **분석** 버튼을 누르세요.

## 지원 범위 및 제한 사항

- 유튜브: 공개 영상, 쇼츠 등 (연령 제한/비공개/로그인 필요 영상은 지원되지 않을 수 있습니다)
- 인스타그램: 공개 계정의 릴스·동영상 게시물, (gallery-dl 설치 시) 이미지/카드뉴스 게시물. 비공개 계정 콘텐츠는 지원되지 않습니다.
- **화면 글자 추출**은 영상 길이에 따라 다소 시간이 걸릴 수 있으며(프레임 샘플링 + OCR), 화질/폰트에 따라 인식률이 달라질 수 있습니다.
- 각 플랫폼의 서비스 정책 변경에 따라 일부 기능이 예고 없이 동작하지 않을 수 있습니다.

## 기술 스택

- Backend: Node.js, Express
- 영상/메타데이터 추출: `yt-dlp` (시스템 PATH에 설치된 실행 파일을 직접 호출)
- 이미지(카드뉴스) 추출: `gallery-dl` (선택 설치)
- 프레임 추출: `ffmpeg` (ffmpeg-static)
- OCR: `tesseract.js` (한국어 + 영어)
- Frontend: 순수 HTML/CSS/JavaScript
